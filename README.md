# 📱 Google Play Store App Review Analysis

An end-to-end **Exploratory Data Analysis (EDA)** project analyzing over **10,000 Android applications** to identify the factors influencing app success, customer engagement, ratings, installs, and user sentiment.

## Business Objective

This project answers the following business questions:

* Which app categories generate the highest installs?
* Do Free apps perform better than Paid apps?
* How do ratings influence popularity?
* What do customer reviews reveal about user satisfaction?
* Which insights can help Product Managers and Developers improve app performance?

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Google Colab

## Project Workflow

1. Data Cleaning
2. Feature Engineering
3. Univariate Analysis
4. Bivariate Analysis
5. Multivariate Analysis
6. Statistical Testing
7. Sentiment Analysis
8. Business Recommendations

## Key Insights

* Family and Game categories dominate the marketplace.
* Communication apps achieve the highest installs.
* Ratings above **4.2** strongly correlate with successful applications.
* Reviews have the strongest positive relationship with installs.
* Positive customer sentiment outweighs negative feedback.
